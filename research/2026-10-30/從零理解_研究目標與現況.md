## 1. 先用一家工廠理解問題

想像工廠收到一張訂單：高等級750件、低等級150件。

原料經過數個加工站，最後會分成高品、低品及不合格品。機台可能停機，因此這期能加工多少不一定；即使完成相同件數，品質分類也可能不同。

高品可以拿去補低品訂單，但通常只能收低品售價。部分低品可能因某個尺寸偏差而可修，經過指定工序後有機會升為高品。其他低品可能根本不適合這條返修路徑。返修還會占用正常加工也要用的產能，而且送回去時尚不知道會成功幾件。

於是有兩個真正的決策：

1. 加工之前，這期要承諾投入多少件原料？
2. 初次加工與檢驗之後，看到實際高低品及可修品，這批要不要啟動返修？

研究希望回答：**怎麼作這兩個決策，才能讓高低等級一起交足的機率達到要求；以及哪些要求在目前條件下做不到？** 在滿足服務要求的政策中，仍以期望利潤選擇較好的方案。

「利潤不是主結果」是論文敘事的定位，不是把數學目標刪掉。現有模型仍是在共同服務限制下最大化期望利潤；只是公平比較後，增益沒有大到適合當主要賣點。

## 2. 「完整履約」究竟是什麼

750/150這張訂單，必須同一次同時交足750高品與150低品，才算成功。

例如交出749高品與160低品，即使總共909件，這張訂單仍未完整履約。單看總件數、平均出貨件數，或高低品分開的達標機率，都不是同一個指標。

服務目標75%的意思是：在模型所描述的重複容量與品質結果中，完整交足的機率至少.75。它不代表每次只交75%的件數，也不代表現場已經被證明達標。正式目標需要教授與案例情境核定；75%、80%、85%、95%目前是研究用的不同目標。

## 3. 現在主模型只保留這條時間順序

`先選整數投入 → 知道容量後按固定規則正常加工 → 檢驗並辨識可修品 → 決定啟動返修 → 才知道成功幾件 → 替代與交貨`

| 時點 | 已知道什麼 | 可以決定什麼 |
| --- | --- | --- |
| 事前 | 訂單、假設的機率與成本 | 投入整數件數I |
| 容量揭露後 | 本期各站容量 | 執行固定正常流，這裡先不另外最佳化正流 |
| 初次檢驗後 | 高品A、低品B、可修低品E、返修餘裕 | 是否啟動返修 |
| 返修之後 | 成功數Y | 按固定替代規則交貨並計帳 |

後面的決策不能偷看還沒有發生的成功數。已知容量也仍是模型假設；如果現場容量只能加工後才得知，就需先處理這個資訊差異。

螺桿直徑單向減少、回最後一站，是目前用來算的候選例子；工序名稱有原文依據，真正的可修方向、成功率及其他尺寸不受影響尚未實證。它不是整篇研究必須綁死的唯一產品。

多期、退化、全部返修路徑、最後站正常量一起控制，現在不列為主軸。可選替代與低剩餘價值時的部分返修也先保留為邊界材料，不繼續擴張。

## 4. 最少需要懂的八個符號

| 符號 | 白話意思 |
| --- | --- |
| I | 事前投入幾件原料 |
| N | 正常加工後完成幾件，採整件取整 |
| A、B | 初次高品、低品件數 |
| E | 低品中符合指定返修資格的件數 |
| R | 這次最多能送回幾件：同時受E、低品需求保留量及餘裕限制 |
| r | 實際送回幾件 |
| eta | 每件返修成功的假設機率；不是正常站良率 |
| alpha | 高低品共同完整交足的目標機率 |

例如低品已有160件、低品需求150，最多只能從這個保留規則下取出10件；即使可修品有30件、返修餘裕有40，也不能任意送回30件。這解釋了為什麼「二級品都送去升級」不合理。

目前售價與剩餘價值滿足特定正邊際條件，因此一旦值得開返修，正返修量中最大R可支配較小量，才能縮成0或R。若終端高品價值改低，這個結論不一定成立；第77輪已有27或28件勝過40件的反例。不能把現有二元求解器當所有經濟情境的通用最適解。

## 6. 三個最值得先理解的結果

**第一，平均產量看起來夠，完整交貨機率仍可能很低。**

500/300、投入1152，在相同N取整與整件回流規則下：

| 評估方式 | 服務機率 |
| --- | --- |
| 平均初次分類＋平均返修成功數 | .96558817 |
| 初次分類隨機，只將成功數改為eta*r | .5096676751 |
| 初次分類與返修成功皆隨機 | .5096676774 |

此例後兩列只差約2.35×10⁻⁹，巨大差距主要來自把初次分類件數換成平均後，硬門檻將某容量群一次判為全部成功。不是每個訂單都能作同樣歸因：650/250、投入1297，後兩口徑分別.47312184與.48917364，未來成功的平均化也會影響服務。

平均法甚至可能低估，所以不能說它固定偏樂觀。若500/300要求95%服務，平均法的最小投入1152不夠，完整模型需要1184，服務約95.26%。這是指定最大回流規則下的投入比較，不是經濟VSS。

**第二，平均品質相同，不代表批次表現與投入決策相同。**

750/150、75%目標、F2000、原料全承諾，逐件獨立模型選1495；同平均但有假設批次波動時，kappa1000選1523、kappa100選1687。kappa是批次波動的壓力參數，現在沒有工廠估計值。

kappa100政策的服務.750003553只比.75高約3.553×10⁻⁶；這只能說該假設法則內算出的可行政策，不能稱現場或未知分布下穩健達標。模擬區間下界未過75%與精算值略過75%可以同時成立；模擬是核對程式與法則，沒有替參數正確性背書。

**第三，有些訂單不值得重工，這也是結果。**

同規則、同目標且基準也重選投入後，四組選擇政策相對最強可行基準的利潤增益約0、105.51、109.17、65.86。550/350最好就是不重工。研究不應承諾普遍大幅獲利；更有力的是說清服務風險、可修限制，以及什麼條件下應改投入或承認目標不可行。

## 7. 哪些只是條件內結論

三種不確定性要分開：機台容量隨機、單件四項品質特性之間相依、同批不同件共享環境造成批內相關。它們不是同一個「相關係數」。

第59輪螺桿候選免費完美返修上界約.810392，依賴獨立KQC等假設；只知道四項邊際時，第60輪的樂觀構造可到.961278。因此沒有排除工廠85%目標，僅排除某個明列模型內的目標。

「精確」指把指定有限機率法則積分，而非只有抽樣估計；仍用雙精度數值，不是正式區間算術保證。最適差距界是在指定模型內的利潤差距，與現場可信度、服務緩衝或抽樣區間是不同東西。

第84輪也未估出工廠kappa；它只核對已知p、批量外生等條件下的矩關係。要識別實際批次波動，仍需多批件數、批次ID與製程設定。
